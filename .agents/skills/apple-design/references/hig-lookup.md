# HIG reference lookup

Pulled from developer.apple.com on 2026-10-02 by the upstream [apple-design-skill](https://github.com/dickwu/apple-design-skill) and trimmed to the pages that applied to the iPhone/iPad app it was first curated for. Koda targets iPhone and Mac: read the `Desktop (macOS)` sections of these pages, and fetch removed macOS-only pages from Apple's site when needed.

72 guideline files and 1 curated guide live in `references/hig/`. Each file keeps Apple's text and headings, relabels platform headings by device class (phone, tablet, mobile, desktop), and omits guidance that only applies to tvOS, visionOS, or watchOS. Load only the files a review needs; the "Covers" column is Apple's own summary of the page.

## Pages left out

Pages that only apply to macOS (menu bar, windows, pointer, panels, column and outline views) and pages about Siri, App Shortcuts, widgets, Control Center controls, and other technologies were removed from this local copy. Koda **does** ship on the Mac and plans Siri/App Shortcuts, widgets, and a Control (PLAN section 7): read those pages on [developer.apple.com](https://developer.apple.com/design/human-interface-guidelines/) when working on them. Links to them inside the kept pages point at Apple's site.
